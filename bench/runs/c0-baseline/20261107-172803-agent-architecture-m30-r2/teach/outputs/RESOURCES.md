# Agent architecture Resources

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, structured note-taking, just-in-time vs pre-retrieval, sub-agents. Use for: anything on context and memory design (primary source for O3).
- [Docs: "Context windows" (Anthropic)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, turn-by-turn accumulation, caching, overflow. Use for: exact facts about the window and token accounting.
- [Docs: Memory tool (Anthropic)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  File-based memory for persisting notes across sessions. Use for: when building save/read notes tools.
