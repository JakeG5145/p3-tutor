Context and memory (one page)

IdeaIn short
Context windowAll text the model sees in one call, output included. Limited; every token costs.
Between stepsThe program resends the whole growing transcript each call. The model keeps nothing.
Between sessionsNothing, unless you save it and load it back.
NotesSmall stable facts (a student's training date) in a file; read at the start, updated at the end.
RetrievalSearch a large store, put only the best few chunks in the window.
Live factsUse a tool (calendar), not a note.
Context rotMore tokens can mean worse recall; keep context small and relevant.

Cost rule: input tokens = the sum over all calls of the whole context at that call, so a long tool result is paid for again by every later call.

Sources: Effective context engineering, Context windows, Memory tool.
