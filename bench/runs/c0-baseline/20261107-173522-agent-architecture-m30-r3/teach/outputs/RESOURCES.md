# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, compaction, note-taking and just-in-time retrieval. Use for: any context or memory design decision.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, context rot, compaction and context editing. Use for: token and cost questions.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file memory across sessions, with safety guidance. Use for: designing what the assistant saves between visits.
- [Article: "Introducing Contextual Retrieval" (Anthropic)](https://anthropic.com/research/contextual-retrieval)
  Chunking, keyword versus embedding search, and measured results. Use for: making manual search find the right page.
